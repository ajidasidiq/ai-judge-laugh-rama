One office-life joke, written to make the AI judge laugh: the office plants died months ago and nobody noticed, because the only thing anyone waters in this office is the rumour about layoffs. A true observation, a surprising last word, and nothing wasted.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (one line, 134 characters).
